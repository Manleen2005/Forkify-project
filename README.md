# forkify Project

Recipe application with custom recipe uploads.
"Built as a hands-on project during Jonas Schmedtmann's The Complete JavaScript Course, focusing on advanced modern JavaScript, architecture, and deployment."
# Features and Implementation
Architecture: Implemented the Model-View-Controller (MVC) pattern to separate business logic from the UI.

State Management: Developed persistent bookmarking using the browser's localStorage API.

Feature Extension: Built the custom recipe upload form and adjusted servings calculation dynamically.
